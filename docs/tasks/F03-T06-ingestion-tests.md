## Description

Integration tests on fixtures that prove idempotency, failure recovery and reconciliation.

## Steps

1. Hand-made fixture CSVs (fictitious values) incl. a malformed row and a wrong-encoding file
2. Tests: run twice → same count; kill/restart; corrupt rows isolated; manifest = bronze
3. Mark as `integration`

## Acceptance criteria

- [x] All ingestion tests pass in CI

## Deliverables

- `tests/fixtures/sipni/`
- `tests/integration/test_ingestion.py`

## Why this matters (best practice)

Idempotency is a claim until it is tested. Tests that re-run and interrupt the pipeline turn reliability into evidence.

## Notes

- Test data is generated by `tests/sipni_fake.py` (fictitious rows in the real format) instead of static fixture files, so the fixtures follow the contract automatically.
- Key test: a crash **after** the Delta commit and **before** the checkpoint commit. On restart Spark replays the batch and Delta skips it without even reading the data (0 input rows, only two `WRITE` commits).
- Full suite in WSL2: 105 tests green before the performance fixes; integration tests re-run green after them.
